# 株式会社ハウスワーク LINE あいさつメッセージ

友だち追加の直後に自動で届くメッセージ。吹き出し3つ（ごあいさつ／AMANOMA オープンルームの案内／オリジナル家づくりBOOKの案内＝資料請求ボタンへ誘導して締め）で構成。

- `greeting.txt`：管理画面に貼り付ける文面（吹き出し1〜3）
- `greeting_mock.jpg`：トーク画面での見え方（リッチメニュー付き）
- `greeting.html`：モックの元データ

## 設定手順（LINE Official Account Manager）

1. 「ホーム」→「あいさつメッセージ」を開く
2. 吹き出し1のテキストを貼り付け、冒頭の `{友だちの表示名}` は「友だちの表示名」ボタンで挿入し直す
3. 「＋追加」で吹き出しを増やし、吹き出し2・3のテキストを貼り付け
4. プレビューで確認して「変更を保存」

※ 1つの吹き出しは500文字まで。LINEのテキストは色・太字などの装飾はできません。

## コピー用

`copy/吹き出し1.txt`〜`copy/吹き出し3.txt` は、注記なしでそのまま貼り付けられる本文。
吹き出し1は「さん、はじめまして。」から始まるので、貼り付けたあと先頭に「友だちの表示名」ボタンで名前を挿入する。
