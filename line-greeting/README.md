# 株式会社ハウスワーク LINE あいさつメッセージ

友だち追加の直後に自動で届くメッセージ。吹き出し2つで構成。

- `greeting.txt`：管理画面に貼り付ける文面（吹き出し1・2）
- `greeting_mock.jpg`：トーク画面での見え方（リッチメニュー付き）
- `greeting.html`：モックの元データ

## 設定手順（LINE Official Account Manager）

1. 「ホーム」→「あいさつメッセージ」を開く
2. 吹き出し1のテキストを貼り付け、冒頭の `{友だちの表示名}` は「友だちの表示名」ボタンで挿入し直す
3. 「＋追加」で吹き出しを増やし、吹き出し2のテキストを貼り付け
4. プレビューで確認して「変更を保存」

※ 1つの吹き出しは500文字まで。LINEのテキストは色・太字などの装飾はできません。
